Calculator 🧮
A simple and responsive calculator web app built using pure HTML, CSS, and JavaScript — no frameworks, no libraries.


🛠️ Technologies Used

HTML
CSS
JavaScript

✨ Features

Basic arithmetic operations (addition, subtraction, multiplication, division)
Clean and minimal UI
Responsive design — works on mobile and desktop
Real-time input display
Clear/reset button

│
├── index.html

git clone https://github.com/sangsingh01/calculator.git
